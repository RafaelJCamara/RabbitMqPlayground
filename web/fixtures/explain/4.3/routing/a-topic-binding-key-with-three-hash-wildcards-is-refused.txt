    pattern  #   | #

  ✓ t -> queue wild ("a.#.b.#.c") [matches]
    The pattern "a.#.b.#.c" matches the key "a.b.c": # took no words; # took no words. The queue wild had a copy already, and a queue gets one copy of a message however many bindings match.
    pattern  a   | #   | b   | #   | c
    key      a ✓ | - ✓ | b ✓ | - ✓ | c ✓
  ✗ t -> queue literal ("##.#.#") [first word is "a", not "##"]
    The pattern "##.#.#" does not match the key "a.b.c": the first word of the key is "a", and the pattern asks for "##".
    pattern  ##  | #   | #
    key      a ✗ | - ✓ | b.c ✓

queue wild: reached through ✓ t -> queue wild ("#.#") [matches]

  The queue literal did not get the message.
  - The binding from t to queue literal ("##.#.#") was tried, and it did not match. The pattern "##.#.#" does not match the key "a.b.c": the first word of the key is "a", and the pattern asks for "##".
  - d is bound to queue literal ("#.#.#"), but the message never reached d.
    - Nothing is bound to the exchange d, so nothing leads into it and the message cannot reach it.
